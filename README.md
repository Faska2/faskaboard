# 🎨 FaskaBoard

**FaskaBoard** is a professional, high-performance architectural whiteboard application designed for designers, architects, and creative thinkers. Built with React, Konva, and Tailwind CSS, it offers a buttery-smooth drawing experience with advanced object manipulation and project persistence.

![FaskaBoard Preview](https://via.placeholder.com/1200x600?text=FaskaBoard+Professional+Whiteboard)

## ✨ Features

- **🚀 Professional Toolset**: Rectangle, Circle, Line, Arrow, Freehand Pencil, Text, and Image support.
- **📱 Fully Responsive**: Seamless experience across Desktop, Tablet, and Mobile with adaptive toolbars.
- **✨ Premium UI/UX**: Modern glassmorphism design, dark mode support, and smooth micro-animations.
- **📂 Project Management**: Real-time auto-save to local storage and a "Recent Boards" dashboard.
- **📥 Import/Export**: 
  - **PNG/SVG**: Export your masterpieces in high quality.
  - **JSON**: Save and load full project files for future editing.
- **⌨️ Keyboard Shortcuts**: Pro-level efficiency with shortcuts for every tool (Undo, Redo, Duplicate, Delete, etc.).
- **📏 Architectural Precision**: Toggleable grid system, object alignment (Top, Bottom, Left, Right), and layering (Bring to Front, Send to Back).

## 🛠️ Tech Stack

- **Framework**: [React.js](https://reactjs.org/)
- **Canvas Engine**: [React-Konva](https://konvajs.org/docs/react/index.html)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Utilities**: [UUID](https://github.com/uuidjs/uuid), [File-Saver](https://github.com/eligrey/FileSaver.js)

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Faska2/faskaboard.git
   cd faskaboard
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```
